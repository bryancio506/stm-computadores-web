## Marca corporativa

Como alternativa a un lockup de Microsoft 365 no localizado, se incorpora el logo corporativo oficial de Microsoft:

- Archivo: `dist/assets/microsoft/microsoft-logo.png`.
- URL: https://img-prod-cms-rt-microsoft-com.akamaized.net/cms/api/am/imageFileData/RE1Mu3b?ver=5c31 .
- Referencia: recurso `itemprop="logo"` del encabezado global de microsoft.com.
- Dimensiones: 216 × 46 px, PNG transparente.
- Verificación visual: símbolo Microsoft de cuatro colores y palabra Microsoft en gris. Usar sobre fondo claro.

La marca corporativa se mantiene completa; no se le añade “365” para construir un logotipo alternativo. El nombre Microsoft 365 puede aparecer como texto independiente de la sección.

No se descargaron ni crearon sellos Microsoft Partner, Gold, Solutions Partner ni de certificación.
